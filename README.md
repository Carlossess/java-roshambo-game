# Roshambo Game (Java)

A Java command-line game where the user plays Rock-Paper-Scissors against the computer.

## Features
- User selects the number of rounds
- User can choose rock, paper, scissors, or quit
- Computer choice is randomized
- Tracks player and computer scores
- Validates user input to prevent invalid entries

## Technologies
- Java
- Eclipse
- Git & GitHub

## How to Run
1. Open the project in a Java IDE
2. Run `Roshambo.java`
3. Follow the console prompts

## Concepts Used
- Methods
- Loops
- Conditionals
- Input validation
- Random number generation
